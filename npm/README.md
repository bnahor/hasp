# hasp-cli

Installs [hasp](https://github.com/bnahor/hasp) — a coding agent with a TUI,
a daemon and a native desktop app — from its GitHub release.

```sh
npm install -g hasp-cli
hasp --version
hasp-desktop        # the native app
```

Prebuilt for macOS (Apple silicon, Intel) and Linux x86_64. Elsewhere, build
from source: see the repository README.
